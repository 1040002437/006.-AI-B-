| 轮次 | 用户反馈 | 结论 |

| — | 用户给出例图 | 例图**就是项目里已有的** `视频脉络-从一个文件夹到全自动产出.png`（2000×1120，`draw_figure_0001.py` 画的）。**三次否定的根源是重画时忽略了它已经存在** |

**最终拍板（当前规范）**：

1. **图形态 = 横向扁宽阶段流 + 动作盒**，约 2000×900～1200（**不要竖版长图**）
2. **结构**：顶部标题+副标题（副标题点明按哪几段重排，**不另造「总」色块**）→ 左侧阶段标签含时间码 → 右侧动作盒横排+横向箭头 → 阶段间竖向箭头递进 → 末段可通栏
3. **节点 = 阶段 + 动作盒**。盒内= 主文字（提炼的动作短句）+ 副文字。**不是章节标题逐字**
4. **覆盖校验**：每个动作盒的 `chapters[]` 并集必须不重不漏覆盖全部章节；同一章的多个动作**合并进一个盒内多行**
5. **软跳转（纯图片）** —— 不做可点目录/锚点（图片无法分区点击）
6. **分几段、每段哪几个动作，由 AI 自行判断**，硬编码在该篇脚本，**不向用户确认**
7. **每篇自由设计专属脚本**，不做共享绘图库
8. **自适应不裁切**：盒宽按可用宽度分配、标签宽按像素自适应；`--preview` 按 1000px 自检

据此S22/S23/S27/S28 完成、S24 留 `[REDO]`。**下一步 S29（渲染层 + 重跑 `--full`）→ S30（两份 Skill 同步）→ S25（0002 实测）**。
