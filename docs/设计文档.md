# 设计文档

> 项目代号：让 AI 学会看 B站视频
> 定位：**不追求详尽，只锁定方向和功能边界**。细节在实现时补，不预先编造。

---

## 1. 一句话目标

给我一个 B站视频链接 → 产出一份**可以直接在飞书里读**的文档：有全量文字版、有按内容分章节的总结、关键处配截图和时间码，我不用再打开原视频。

## 2. 为什么自己造（现成工具的缺口）

调研结论（2026-10）：

| 能力 | 现成工具 | 说明 |
|---|---|---|
| 下载 B站视频 | ❌ | 通义听悟、飞书妙记均不支持贴链接（合规），必须下载后上传 |
| 全量文字版 | ✅ | 妙记免费档 300 分钟/月，但**只给逐字稿** |
| 章节总结 | ❌ | 妙记「智能纪要」需付费；其余工具多为会议纪要式模板，套在长视频上很别扭 |
| 截图 + 几分几秒 | ❌ | **没有任何现成工具做** |
| 云端随时看 | ✅ | docx 导入飞书即可达成 |

**结论**：免费工具只覆盖了最不缺的一环（转写），真正想要的总结与截图是空白。且用量越大（只看长视频），自建越划算——字幕走 B站官方 AI 字幕，边际成本为 0。

## 3. 总体流程

```
B站链接
  → ① 解析 BV 号 / 分 P
  → ② 下载视频本体（720P）
  → ③ 抓取 B站官方 AI 字幕（wbi 签名 + SESSDATA 登录态）
  → ④ 由 WorkBuddy 读字幕：按内容分段 + 逐段总结 + 标出值得截图的时刻
  → ⑤ 按时间码精确抽帧
  → ⑥ 合成 docx（真标题样式 + 图片内嵌）
  → ⑦ 用户拖入飞书「导入为在线文档」
```

## 4. 目录与文件规范

每个视频一个自包含文件夹，编号 4 位递增，空号不复用：

```
data/
└─ 0001.《视频标题》/
    ├─ video.mp4          视频本体（720P）
    ├─ subtitle.json      B站原始字幕（精确起止秒）
    ├─ subtitle.srt       通用字幕格式
    ├─ 视频信息.md        原链接 / BV号 / 标题 / UP主 / 时长 / 抓取时间
    ├─ frames/            截图，文件名带时间码（00-05-12.jpg）
    └─ 《简短标题》.docx   最终文档（图片内嵌，可直接导入飞书）
```

- **docx 命名**：不用固定的 `report.docx`，用**真实视频标题的精简版**（≤20 字左右，可按内容概括，但必须与原视频标题有呼应，看到文件名就能对上是哪个视频）；例：`0001.《【豆包实操】从个人知识库到自动化：…》/` 里放 `《豆包实操：知识库到自动化》.docx`
- **docx 内容**：文档开头写明**视频原链接**（可点击），方便随时跳回原视频
- **命名清洗**：去掉 Windows 非法字符 `\/:*?"<>|`，标题超过 60 字截断加 `…`
- **重复链接**：同一 BV 号已存在 → 提示「已存在（0001）」，不重复下载、不新建编号
- **分 P 视频**：默认只处理链接指定的那一 P；链接不带 P 号而视频是多 P 时，先提示选择
- **产物位置**：报告与截图都放在该视频自己的文件夹内，不另建 `outputs/`

## 5. 主要功能清单

| # | 功能 | 说明 | 阶段 |
|---|---|---|---|
| F1 | 链接解析 | 正则抽 BV 号，丢弃 `?spm_id_from=` 等追踪参数，识别分 P | MVP-0 |
| F2 | 建目录 | 按 `0001.《标题》` 建文件夹，写入 `视频信息.md` | MVP-0 |
| F3 | 下载视频 | yt-dlp 拉 720P，音视频自动合并 | MVP-0 |
| F4 | 抓 AI 字幕 | 带 SESSDATA 调 wbi 签名接口取字幕，转 SRT | MVP-0 ✅ 已跑通 |
| F5 | 全量文字版 | 带时间戳按段落输出，一级标题《视频全量文字版》 | MVP-0 |
| F6 | 章节总结 | 由 WorkBuddy 读字幕分段并逐段摘要，二级标题 = 章节 | MVP-0 |
| F7 | 关键帧截图 | 按总结时标出的时刻精确抽帧，图下标注「📍 00:23:15」 | MVP-0 |
| F8 | 合成 docx | 真 Heading 1/2 样式 + 图片内嵌，供飞书导入 | MVP-0 |
| F9 | 一键串联 | 一条命令跑完 F1–F4，后续步骤交给对话 | 后续 |
| F10 | 直接写入飞书 | 走官方 API 建文档插图（需 App ID / Secret） | MVP-1 |

## 6. 技术选型

| 环节 | 方案 | 理由 |
|---|---|---|
| 视频获取 | `yt-dlp` | 稳定、纯 pip，不需装系统软件 |
| 音视频处理 | `imageio-ffmpeg` | pip 包自带 ffmpeg 二进制，**换台电脑也能跑** |
| 文字来源 | B站官方 AI 字幕 | 零成本、秒级、准确度高于任何 ASR |
| 登录凭证 | `SESSDATA` 存 `.secrets/` | 已 gitignore，绝不入库 |
| 总结 | **由 WorkBuddy 在对话中完成** | 不用配 LLM Key，零额外成本，质量优于模板化摘要 |
| 文档合成 | `python-docx` | 支持真标题样式与图片内嵌 |

## 7. 明确不做

- Web 界面 / 浏览器插件（先命令行）
- 批量队列、并发、断点续跑
- ASR 本地转写（除非某视频确实无 AI 字幕）
- 多语言翻译、双语字幕
- 视频内容问答 / RAG 知识库
- 结构化导出（多维表格、JSON schema）

## 8. 质量红线（不达标就报错，不静默出货）

1. **无 AI 字幕 → 直接报错中止**，不静默降级、不产出残缺文档
2. 总结每一节必须落到具体时间点；编不出来则按时间戳等分兜底
3. 文档里每张图必须带「几分几秒」标注，无标注的图不许进文档
4. docx 必须用真 Heading 样式（不是加粗），否则飞书不生成大纲
5. 图片必须嵌进 docx 包内，不能是外部引用，否则导入飞书后图全丢

## 9. 里程碑

- **M0（当前）**：F1–F4 跑通 —— 给链接就得到一个整齐的素材文件夹
- **M1**：F5–F8 跑通 —— 从素材到一份可导入飞书的 docx
- **M2**：F9 一键串联 + F10 直写飞书
